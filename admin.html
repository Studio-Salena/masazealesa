📈 Účetnictví

Čtyři různé věci, záměrně oddělené — nejde o jedno číslo. Tržby za služby = hodnota odvedené práce podle data masáže. Přijaté platby = skutečný pohyb peněz (poukaz se tu nepočítá znovu, ten už je v „Prodej poukazů“). Prodej poukazů = kdy se prodaly. Vráceno = kolik se vrátilo klientkám.

📷 Naskenovat kód poukazu

+ Vydat dárkový poukaz

+ Přidat variantu poukazu

+ Přidat masáž / variantu do ceníku

Pokud masáž (skupina) už existuje, napiš stejný název jako u ní — přidá se jako další varianta pod ni. Pokud je nová, vytvoří se nová skupina.

+ Přidat zákaznici

Detail rezervace

+ Přidat rezervaci

Jde i mimo běžnou otevírací dobu — hodí se pro klientky domluvené mimo web. Rezervace se rovnou založí jako potvrzená a pokud vyplníš e-mail, hned se jí pošle potvrzovací e-mail.

+ Přidat výjimku provozu

Bez vyplněné otevírací doby níž = celý den zavřeno (dovolená, svátek). S vyplněnou otevírací dobou = pro tyhle dny platí místo běžného rozvrhu tahle (např. jeden den v měsíci delší otevřeno).
